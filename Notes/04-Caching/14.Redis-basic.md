## Redis Basics for HLD

<h2>What is Redis?</h2>

**Redis is a fast in-memory data store commonly used for caching.**

```text
Application
     ↓
   Redis
     ↓
    DB
```

<h2>Why Redis?</h2>

- Very fast because data is stored in **RAM**.
- Reduces **database load**.
- Supports **TTL** and **eviction policies**.
- Can be used as a **distributed cache**.

<h2>Example</h2>

```text
User requests product
        ↓
      Redis
        ↓
   Cache HIT 
        ↓
     Response
```

<h2>Key Point</h2>

> **Redis = fast in-memory data store commonly used for caching.**

<h2>Remember</h2>

```text
RAM → Very Fast
Redis → Cache
Cache → Reduce DB Load
```
